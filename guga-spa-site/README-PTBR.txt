GUGA SPA - PROJETO PREPARADO PARA PUBLICAÇÃO

Este pacote organiza seu código React para poder ser publicado como site e depois incorporado ao Google Sites.

PRÓXIMOS PASSOS:
1. Extraia esta pasta no computador.
2. Envie os arquivos da pasta para um repositório GitHub.
3. Importe o repositório no Vercel e publique.
4. Copie o endereço público gerado pelo Vercel.
5. No Google Sites, use Inserir > Incorporar > Por URL e cole o endereço.
6. Ajuste o tamanho do quadro incorporado e publique o Google Sites.

OBSERVAÇÃO:
O Google Sites não executa diretamente este projeto React. O Vercel hospeda a aplicação e o Google Sites a exibe incorporada.
Os eventos, rankings e arenas do código atual ainda são dados demonstrativos; não há banco de dados ou login funcional.
